How it works

One ticker in, one rated decision out

Each agent is a role with its own instructions in tradingagents/agents/. The framework runs them as a LangGraph pipeline on any LLM provider.

Research in parallel

Four analysts pull prices and indicators, filings, news and macro data, and social posts, then each writes a report ending in a summary table.

Debate the thesis

A bull and a bear argue from those reports. The research manager rates the case on a five-tier scale. Disagreement alone is never a reason to hold.

Write the order

The trader turns the rating into a buy, hold or sell with entry and stop as exact prices, grounded in the technical levels.

Stress-test and sign

Three risk analysts argue the size and stops. The portfolio manager weighs them, sets the final rating, and names what would change it.

Run the framework

Needs Python 3.11+, an LLM API key, and access to Yahoo Finance and SEC EDGAR.

export ANTHROPIC_API_KEY=...
